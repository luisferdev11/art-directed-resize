The problemwhy a resize is not enough

Adapting a campaign to dozens of formats is decision work, not scaling work. The usual mechanism — three hand-authored templates with constraints, each output matched to the closest one by size — moves boxes according to rules fixed in advance.

A constraint cannot look at the photograph. It does not know where the face is, whether the headline is still legible over whatever ended up behind it, or that at 8:1 the photograph should stop bleeding altogether. It works while the target resembles a template, and a campaign does not resemble three templates.

What this engine doesthe decisions it actually makes

DecisionHow it is taken
RolesDeduced from type size, area and relative hierarchy. Layer names are never read: rename everything to "Layer 1" and the result does not change. Depending on names would mean asking for a file authored for the tool.
CropDense search over 7 scales and 13×13 positions, with the subject as a hard constraint and a floor and ceiling on subject scale.
PlacementNot picked from a list of anchors: searched over a cost field derived from the pixels — saliency, luminance variance and gradient — with the face region ruled out for text.
ContrastWCAG luminance by percentiles, measured line by line. Where it falls short, the minimum scrim alpha is found by compositing in sRGB, which is where SVG actually composites.
DegradationA stated ladder, applied in order: drop_legal, tighten_leading, weight_for_size. Nothing is silently squeezed: if it does not fit, something goes and the reason is recorded. In this campaign what went was: legal.
StructureWhen no bleed crop can hold the subject, the photograph degrades to a side panel and the brand field is promoted. That is a decision emerging from a measured constraint, not a per-format template. It happened in: leader_728.
OutputEditable SVG: one <text> per line with absolute baselines and the fonts alongside. Verified: it imports into Figma with layers and editable text.

The architecturea single seam

Scene is the only coupling point in the system. File formats are adapters at both ends, and the decision engine is interchangeable. That is why the rival mechanism could be implemented as a second backend against the same model, and why a Figma plugin would be a third adapter rather than a separate project.

For a flat JPEG there is nothing to parse: zero text nodes, zero roles, zero hierarchy. There a multimodal model reads the piece and assigns each role by communicative function, which is the one thing only a model can do; the pixels and the font metrics then measure where everything sits and how large it is. Burned-in text is removed with classical inpainting so the artwork can be recomposed underneath. If the schema does not validate, the chain falls through to the next provider and the failure is recorded.

Down the constraint route, the only thing that changes when you change the photograph is which pixels get cropped: type sizes, colours, scrims and dropped elements are identical. That is the thesis, measured.

Role assignment: reading the piece scores 12/12 frente a 9/12, sobre N=3 masters against ranking by type size. The whole difference is one deliberately constructed case, and a real one: a legal notice set in large type, which turns up in any regulated promotion. Ranking by size gets 1 of 4 right there.

N=3 does not support a model comparison, and is not presented as one. It supports the claim that this class of artwork exists and that ranking by size fails on it by construction.

What it does NOT dosaid before anyone has to ask

  • It does not orchestrate campaigns: no bulk grouping, no bulk naming, no video export, no round trip back into the design tool through a plugin. It is the layout engine, not the product.
  • Copy does not vary per centre. All three centres carry the same headline and the same dates. What changes is the photograph.
  • Exactly one field of the scene goes unverified: typographic weight on the flat-JPEG path. Deriving it was attempted and made the result worse, so it is stated rather than implying everything is measured.
  • The plate reconstructed under burned-in text is an approximation: beneath a 92px headline the inpainting invents plausible texture, not the original.
  • A group is harder than a person, and it shows. When the subject is a group the focal region is a wide extent rather than a face, so it is maximised instead of required: at 4:5 and 1:1 it holds on a bleed crop, at 8:1 the photograph still degrades to a side panel, and in a 300×250 MPU the headline ends up over faces — the triage flags exactly those. Measured on three group photographs, not argued from one.
  • No interface. The pages on this site are generated static reports.

Reproducing it

pip install -r requirements.txt        # opencv-CONTRIB, not opencv-python

./run.py --backend both                # both layout backends
./check.py                             # re-parse and measure the delivered SVG
python3 tools/swap_test.py             # one master, three photographs
python3 tools/golden.py                # role assignment, with its N
